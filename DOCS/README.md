# 项目文档中心

本目录集中保存轻量外卖平台的课程报告、需求追踪和架构说明。项目代码和运行入口仍保留在仓库根目录。

## 文档导航

- [需求规格说明书 PDF](./report/tjumain.pdf)：供直接阅读和提交的编译版本。
- [SRS LaTeX 源码](./source/README.md)：报告正文、图片和排版配置。
- [SRS 实现进度](./SRS实现进度.md)：需求条目与当前功能实现的对应关系。
- [架构与改需求指南](./架构与改需求指南.md)：代码分层、业务规则归属和需求变更方式。

## 编译 SRS

进入 `DOCS/source` 后执行：

```bash
make pdf
```

生成结果位于 `DOCS/report/tjumain.pdf`。

## 目录约定

- 课程报告、需求分析、UML 图和开发说明统一放在 `DOCS/`。
- 根目录的 `README.md` 作为 GitHub 项目首页保留。
- 根目录的 `SECURITY.md` 按 GitHub 约定保留，用于说明密钥和演示功能边界。
- 业务源码、测试和部署脚本不要放入 `DOCS/`。
