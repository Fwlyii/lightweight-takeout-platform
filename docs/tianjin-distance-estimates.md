# 天津首页距离与预计送达时间

按展示需求，首页及分类商家列表只替换原有距离、送达时间文本，不增加定位面板或说明标签，也不请求设备定位权限。

- 默认和选择津南区时，以北洋园周边的展示起点（39.001, 117.315）计算；天津其他区使用对应区域坐标。
- 保留商家原地址：卫津路校区不迁到津南，和平区商家不伪装成校内商家。
- 已有演示商家按“ID + 名称 + 原地址”匹配不同的固定展示点位，点位仍在原校区/区域，不随机生成，不声称是真实门店 GPS 坐标。用户明确要求展示距离有合理差异。
- 未配置点位的校区级地址解析到该校区，行政区级地址解析到对应区域。真实有效经纬度优先于展示点位。
- 当前演示目录中的“天津大学”泛地址按北洋园校区处理。以后要提高精度，应补充更完整的门店地址/坐标，而不是继续扩大名称猜测。
- 界面统一显示“约 X.X km”和“约 X 分钟送达”，为区域级展示估值，不是 GPS 实时距离、真实路线或配送承诺。
- 选到天津之外、地址无法解析时，距离与送达时间同时恢复“暂无”，不会沿用上一次天津的数值。
- 时间公式：15 分钟备餐 + 5 分钟调度 + 直线公里数 × 1.3 路网系数 ÷ 18 km/h × 60，向上取整到 5 分钟，最少 25 分钟。不把跨区远单强行截短。

数据依据（2026-09-16 查验）：

- [天津行政区区域坐标](https://geo.datav.aliyun.com/areas_v3/bound/120000_full.json)
- [北洋园校区](https://mapcarta.com/W476603051)
- [卫津路校区](https://mapcarta.com/W48165383)

全部计算在浏览器本地完成，无地图 API Key、数据库迁移或后端升级要求。

AI 推荐接口缺少商家地址，因此抽屉与完整 AI 页按 businessId 关联同一份公开商家目录，复用本规则以及真实评分、销量。地区切换后重新打开 AI 会读取最新选择，不沿用天津距离。
