# 轻量级外卖服务平台

软件工程综合实践项目。系统面向顾客、商家、骑手和管理员，覆盖店铺与商品、购物车、订单履约、配送、评价、营销资产和智能服务等业务。

## 当前文档

- [需求规格说明书（PDF）](report/tjumain.pdf)：当前可直接阅读的报告。
- `source/body/srs/`：需求规格说明书正文。
- `source/figures/srs/`：UML 图和其他需求分析图。
- `source/setup/`：LaTeX 排版配置。

## 编译报告

进入 `source/` 目录后执行：

```bash
make pdf
```

生成结果位于 `report/tjumain.pdf`。
